## 学习内容

### Handbook 章节：Network

**核心理解**：区块链网络的核心不是“存数据”，而是让互不信任的参与者对状态变化达成一致。

**关键概念**：

| 概念 | 要点 |
|------|------|
| Block | 交易批量提交和排序的单位；有顺序、有 gas limit、可形成可验证历史 |
| Consensus | 网络决定“哪段历史有效”的机制；影响确认数、重组风险 |
| PoS | 验证者质押 ETH 参与区块提议，经济激励维护安全 |
| Testnet | 测试流程和环境，但不能替代主网安全审查 |
| L2 | 主网安全和低成本之间的扩展层，带来桥、提现、跨链等复杂度 |
| Rollup | 主流 L2 方案：optimistic 和 ZK，降低单笔成本但不消除复杂度 |

**AI × Web3 关联**：AI Agent 读取链上状态或执行交易时，必须知道自己在哪条网络——主网/测试网、L1/L2、chain id、合约地址，不能靠模型“猜”。工具应返回结构化信息：chain id、RPC 来源、区块高度、tx hash、确认数、explorer 链接。

**最小实践**：做一笔测试网交易追踪 — 领水 → 转账 → 查浏览器 → 记录 pending→confirmed 时间 → 切换网络对比。
