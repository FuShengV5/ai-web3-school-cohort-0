## 学习内容

背景：Java 工程师，近期自学 Agent 开发，有一定实战经验。参加 AI × Web3 School 主要目标是系统补齐 AI 知识，Web3 作为扩展了解。

### LLM

- 大模型的能力边界：擅长文本理解与生成，不擅长精确计算和实时决策
- Agent 视角：模型是大脑，工具是手脚，LLM 负责推理和规划，具体执行交给工具

### Prompt

- 核心是把任务目标、边界条件和输出格式写清楚
- 对工程实践的启发：Prompt 本质上是一种声明式编程接口，输入越结构化、输出约束越明确，Agent 行为越可控

### Context

- 模型一次能看见的信息有限（上下文窗口），需要精心编排
- 信息的可信度和时效性是关键：模型不知道信息什么时候过期
- Agent 开发中要区分"系统提示""工具返回""用户输入"三类上下文，避免污染

## 与工作的关联

近期在做 Agent 相关项目，LLM / Prompt / Context 三章直接覆盖了日常踩坑的几个点：
- Prompt 质量直接影响 Agent 输出稳定性
- Context 管理决定 Agent 能否在长对话中保持一致性
- LLM 能力边界决定了哪些任务适合自动化、哪些必须人工兜底
