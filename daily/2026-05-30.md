### 学习内容

- **Handbook 章节**：MCP（Model Context Protocol）
- **关键概念**：
  - MCP 四大要素的正确关系：LLM 在 CLI 内部（不是外部），MCP Client 是 Hermes 的内置组件，Permission 在 Client 侧不在 Server 侧
  - CLI 是什么：Hermes CLI = 整车（内含 LLM + MCP Client + 工具系统 + Skill 系统 + 配置管理）
  - MCP 本质：一个协议，让 LLM 能统一调用不同语言不同平台的服务。类比 HTTP——写一次到处接
  - 传统应用 vs Hermes CLI：传统应用功能固定、预制组合；Hermes 功能动态、由 LLM 实时编排
  - 接口约束的第一性原理：Tool Schema 只规定"怎么调"，不保证"调得安全"。权限/审计/隔离需要分层处理（Client 层拦截 + Server 实现层校验）
  - JavaCliTool 可包装为 MCP Server：去掉 LLM 部分，把 Tool 包装成 MCP 协议，Hermes 配置一行即可自动发现调用
- **代码 / 实验**：无
