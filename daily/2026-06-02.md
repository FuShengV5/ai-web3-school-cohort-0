### 学习内容

- **Handbook 章节**：向量知识库（RAG）分级架构 + Fine-tuning 知识节点
- **关键概念**：
  - **向量知识库 Level 0**：规则硬切分块 → Embedding API → 向量存储 → 余弦相似度检索 → Top-k → LLM 回答。适用 Demo，极限在几百个 chunk
  - **向量知识库 Level 1（分水岭：从"能搜"到"搜得好"）**：语义分块（句向量相似度骤降处切分）→ 混合检索（向量 + BM25 关键词精确匹配）→ Reranker（交叉编码器精排 30→top-3）→ Golden Set + Harness 闭环评估。Reranker ≠ LLM 判断：Reranker 做相关度打分，LLM 做信息充足度判断，两者不可替代
  - **向量知识库 Level 2（用户提问端优化）**：查询改写（LLM 优化模糊问题）、多查询分解（拆多个意图分别搜）、Agent 式检索（LLM 分析 top-3 后决定是否改写重搜）、文档解析流水线（PDF/表格/OCR）、多租户隔离
  - **Reranker 定位**：是"守门员"而非"教练"——向量+BM25 粗召回 30 条 → Reranker 精排 top-3 → LLM 判断信息够不够
  - **Skill 本质**：场景对应的操作手册，封装领域专知和流程规范，而非"角色身份"。角色互斥（司机/厨师），Skill 可叠加。类比 Java：角色 ≈ 类继承，Skill ≈ 接口多实现
  - **Agent 工作流退化**：日志格式偏离原因——agent 长期使用后省略了"加载模板"步骤，非模型幻觉。flash 模型格式保持力弱于完整版，但主因是工作流退化
  - **SFT（有监督微调）**：方法。人工标注 QA 让模型学习，最基础的微调方式。DeepSeek 云端微调默认用 SFT
  - **LoRA（低秩适配）**：方法。在层旁插入两个小矩阵，只训练小矩阵（原参数 0.1%~1%），不动原模型权重。训练结果几十 MB。类比 Java：SFT = 全量重新编译，LoRA = AOP 织入补丁
  - **PEFT（参数高效微调）**：方法体系。包含 LoRA / Adapter（层间插入小网络）/ Prefix Tuning（可训练前缀）/ Prompt Tuning（可训练 soft prompt）。LoRA 是最流行的一种，但 PEFT ≠ LoRA
  - **Dataset**：方法（微调成败的基础）。质量 > 数量，人工写正确答案，80/20 分训练/验证集
  - **Overfitting**：理论+方法。模型背答案没真学会（训练集分数高、验证集分数低）。防法：验证集、早停、数据多样性、适量轮数
