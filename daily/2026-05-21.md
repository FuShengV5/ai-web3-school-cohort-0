## 学习内容

### WCB Agent API Key 配置

- 从 AI × Web3 School 平台生成 Agent Secret API Key
- Handbook 文档：https://aiweb3.school/learning-agent.zh.txt
- 配置在 `~/.hermes/.env` 中：
  - `WCB_AGENT_SECRET_API_KEY=<你的Key>`
  - `WCB_BASE_URL=https://web3career.build`
- API 文档：https://web3career.build/llms.txt
- Agent API 端点：`POST /api/agent/call`，使用 Bearer Token 或 `X-Secret-Api-Key` 认证
- Base URL: `https://web3career.build`
