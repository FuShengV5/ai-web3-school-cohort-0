### 学习内容

- **Handbook 章节**：MCP / Skill / Vibe Coding

- **关键概念**：

  MCP（Model Context Protocol）：
  - MCP = AI 应用和外部工具的"USB 接口标准"
  - 四大核心概念：Server（提供工具）、Client（AI 应用端）、Tool Schema（工具定义格式）、Permission（用户授权）
  - MCP 管协议层（工具怎么接），Skill 管应用层（接了怎么用）
  - Java 类比：MCP = JDBC，Skill = Service 类

  Skill 机制：
  - Skill = 场景操作手册 = prompt + plan + tools + rules 的打包
  - 存放在 `~/.hermes/skills/` 下，按需自动加载
  - 知识可跨 CLI 移植（纯 markdown），但工具名和自动加载机制是 CLI 绑定的
  - 其他 CLI 等效机制：Claude Code 的 CLAUDE.md、Codex 的 CODEX.md、Cursor 的 .cursorrules

  LangChain vs LangGraph：
  - LangChain = 线性链，适合确定性多步调用（工厂流水线）
  - LangGraph = 带循环的图，适合需自我检查+修正的场景（软件开发：写→测→改→再测）
  - 关键认知：循环 = Agent 自我检查 → 发现错误 → 回头修正 → 直到正确

  Vibe Coding：
  - 不是 AI 理论，而是实践方法论/场景
  - 描述"人怎么用 AI 来写代码"——人凭"感觉"判断代码对不对，不逐行读
  - 8 个知识节点：从初级工具到高级工作流层层递进
