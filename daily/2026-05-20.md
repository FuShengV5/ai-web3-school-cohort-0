### Hermes 微信接入架构

- Hermes 支持微信接入，适配器在 `gateway/platforms/weixin.py`
- **接入方式：** 通过腾讯 iLink Bot API，走 HTTP 长轮询，**不是直接接入本机微信**
- **架构链路：**
  ```
  手机微信 ←→ 腾讯 iLink 服务器 ←→ Hermes（WSL2）
  ```
- **实际效果：** 在微信里添加一个 iLink bot 身份（xxx@im.bot）作为联系人，跟它聊天 = 跟 Hermes 对话
- **关键限制：**
  - iLink bot 是一个独立的 bot 身份，不是把自己微信号变成 AI 机器人
  - 群聊大概率不可用（iLink bot 收不到普通微信群事件）
  - 依赖腾讯 iLink 服务可用性
- **配置步骤：** 安装 aiohttp + cryptography → `hermes gateway setup` 扫码登录 → `hermes gateway` 启动

### 识别 Hermes 核心

- 之前一直以为 Hermes 是类似于 OpenCode 的同类型工具
- 实际上 Hermes 是一个 Agent 框架：
  - 自己是这个 Agent 框架的"大脑"
  - 框架提供了 tools / skills / memory / cron / gateway 等完整能力
  - 当前运行在 DeepSeek 模型上
  - 不是单纯的"对话工具"，而是一个可扩展的 Agent 平台
