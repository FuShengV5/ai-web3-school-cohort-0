## 学习内容

### 一、Week 1 课程任务解读

**任务：** 做出一个最小可交互 AI 学习产物，帮助学习 AI/Web3 概念。

核心要求：
- 能接受用户输入
- 能给出 AI 生成或辅助生成的输出
- 能帮助理解一个概念、流程、工具或实践任务

可选形式：CLI / 网页 demo / bot / notebook / agent workflow / 概念解释器等。

### 二、Spring AI Agent 构建

基于 Spring AI + Spring Boot 构建的 Handbook 问答 Agent。

### 三、System Prompt 设计

设计要点：
1. 明确知识源：所有回答必须基于 AI × Web3 School Handbook（https://aiweb3.school/zh/handbook/）
2. 回答前先查目录定位章节，再按需抓取章节内容
3. 举例/延申超出 Handbook 时，必须标注并附带可查证 URL
4. 不确定时直接说"Handbook 中没有覆盖这个内容"
5. 严禁凭空编造 API 名称、项目名称、代码示例

### 四、HandbookQueryTools 设计

从一次抓整站改为两个 Tool 分工：

**Tool 1：getHandbookToc** — 获取 Handbook 目录结构，了解有哪些章节可查
**Tool 2：getHandbookSection(sectionPath)** — 按章节路径（如 ai/prompt、web3/network）获取对应章节的详细内容

验证结果：
- 问"解释 LLM" → Agent 定位到 AI 基础 → LLM 章节，给出结构化的概念解释 ✅
- 问"解释 prompt 中的 Instruction" → Agent 定位到 ai/prompt 章节，找到 Instruction 知识节点，给出四段式设计规范 ✅

## 学习问答

**问：为什么 Tool 要从一个拆成两个？**

答：第一次测试发现，只抓 Handbook 首页只能拿到目录结构和章节概要，拿不到每个章节下面的具体知识节点（如 Instruction、Few-shot 等子概念）。拆成两个 Tool 后：先调 getHandbookToc 了解有哪些章节，再按需调 getHandbookSection 抓具体章节的完整内容。
